Soluciones que ya
estamos aplicando

Estos proyectos muestran cómo aplicamos la domótica a necesidades concretas. Cada solución se diseña según el lugar, los recursos disponibles y la forma en que las personas utilizan la instalación.

Proyecto / 01

Aforador para aljibe

Ejemplo open source y DIY

Sistema para conocer el agua disponible en un aljibe sin tener que comprobarlo manualmente.

Una sonda mide el nivel del agua y envía los datos a un panel donde pueden consultarse el porcentaje disponible, el volumen aproximado en litros y su evolución a lo largo del tiempo.

Tecnologías: ESP32, ADS1115, ESPHome y Home Assistant.

Ver el proyecto del aforador
Proyecto / 02

Automatización del riego

Sistema para controlar diferentes zonas de riego desde un único lugar, establecer horarios y activar o detener cada zona manualmente.

Permite adaptar el funcionamiento a las necesidades de huertos, jardines e invernaderos y facilita futuras ampliaciones con sensores o condiciones ambientales.

Tecnologías: Home Assistant, dispositivos conectados y automatizaciones personalizadas.

Proyecto / 03

Control de calefacción

Sistema para supervisar las temperaturas de la instalación y coordinar la calefacción, los circuitos y el depósito de inercia.

La automatización ayuda a aprovechar mejor la energía disponible y mantiene controles manuales para poder actuar directamente cuando sea necesario.

Tecnologías: Sensores de temperatura, actuadores, Home Assistant y automatizaciones.

Proyecto / 04

Monitorización de energía

Sistema para consultar la producción y el consumo eléctrico y comprender cómo se está utilizando la energía.

Los datos permiten detectar consumos, observar su evolución y utilizar los excedentes disponibles de forma más eficiente.

Tecnologías: Medidores de consumo, integración energética y Home Assistant.

Proyecto / 05

Control de climatización

Sistema que activa o desactiva la climatización según la temperatura establecida por el usuario.

Incluye control directo, ajuste de la temperatura objetivo e información histórica para comprobar cuándo ha funcionado el equipo.

Tecnologías: Sensores de temperatura, control conectado y Home Assistant.
